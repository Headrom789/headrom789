### Repository Directory Structure (Template Reference)

For engineering asset repositories under this profile, the standardized file schema is structured as follows:

```text
├── cad/
│   ├── native/             # Parametric CAD models (.f3d)
│   ├── step/               # Standardized STEP files (AP214 / AP242)
│   └── stl/                # Production mesh files for FDM printing
├── docs/
│   ├── drawings/           # 2D PDF manufacturing & dimensioned prints
│   └── specs/              # DFM notes, BOMs, and design criteria
└── media/                  # Assembly renders and verification photos
```
